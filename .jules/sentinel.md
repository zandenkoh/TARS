## 2025-02-18 - Command Injection in ExecTool

**Vulnerability:** The `ExecTool` in `TARS/agent/tools/shell.py` was susceptible to command injection bypasses. Although it used a blocklist pattern (`_guard_command`) to restrict dangerous commands, it executed instructions via `asyncio.create_subprocess_shell` (i.e. `shell=True`). This allowed attackers to craft commands that evade blocklist boundaries and run malicious scripts by abusing shell operators (e.g. `;`, `|`, `&&`, backticks).
**Learning:** Using `create_subprocess_shell` inherently delegates parsing to the system shell (like `/bin/sh`), which makes regex-based blocklisting fragile and prone to evasion. In a lightweight agent architecture with shell execution capabilities, strict enforcement requires shifting away from system shells.
**Prevention:** Avoid `create_subprocess_shell` entirely for user/agent-provided commands. Instead, use `asyncio.create_subprocess_exec` (`shell=False`) coupled with `shlex.split` to safely parse the command string into an argument list. This isolates arguments from the executable, completely negating shell injection vectors while maintaining basic execution capability.
